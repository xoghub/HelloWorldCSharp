# HelloWorldCSharp 🚀

Welcome to my C# learning journey! This repository is a curated collection of foundational exercises and experiments designed to master the basics of C# and the .NET ecosystem.

## 📂 Project Structure

This repository contains several standalone C# scripts, each focusing on a specific aspect of the language:

### Core Concepts
*   **`HelloWorld.cs`**: The essential "Hello World" program, including examples of string concatenation and basic comments.
*   **`variables.cs`**: A deep dive into C# data types (`int`, `string`, `double`, `char`, `bool`), explicit/implicit casting, and type identification using `.GetType()`.
*   **`operatorInAction.cs`**: A comprehensive demonstration of C# operators:
    *   Arithmetic (`+`, `-`, `*`, `/`, `%`)
    *   Comparison (`==`, `!=`, `<`, `>`, `<=`, `>=`)
    *   Assignment (`+=`, `-=`, `*=`, `/=`, etc.)
    *   Logical (`&&`, `||`, `!`)
    *   Ternary operations.
*   **`ForLoop.cs`**: Examples of control flow and iteration using loops.
*   **`whileLoop.cs`**: Demonstrates iterations utilizing `while` loops, including number counting and input validation.
*   **`conditionalState.cs`**: Covers conditional statements including `if/else if/else` logic and `switch` statements.
*   **`logicalOperator.cs`**: Deep dive into logical operators (`&&`, `||`, `!`) and conditional branching based on combined conditions.
*   **`stringMethods.cs`**: Explores common string manipulation methods such as `.Replace()`, `.Substring()`, `.Contains()`, `.ToUpper()`, and more.

### Input/Output & Libraries
*   **`simpleIO.cs`**: Demonstrates basic console interaction, reading user input, type conversion (`Convert.ToInt32`), and advanced string formatting.
*   **`MathLib.cs`**: Explores the `System.Math` class, showcasing methods like `Max`, `Min`, `Pow`, `Sqrt`, `Abs`, `Round`, `Log`, and `Exp`.

### Project Metadata
*   **`HelloWorld.slnx`**: Solution file for organizing the project in modern IDEs.

## 🎯 Goal

The primary objective is to build a rock-solid foundation in C# syntax and logic. By documenting these early steps, I aim to create a reference for myself and others starting their journey in software development with .NET.

## 🛠️ How to Run

To run any of these files, you can use the .NET CLI:

```powershell
dotnet run --project <FileName>.cs
```

*(Note: Ensure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine.)*
