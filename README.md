# HelloWorldCSharp

Welcome! This repository documents my journey of learning C# from scratch. It serves as a collection of my early experiments, basic syntax learning, and introductory concepts in the .NET ecosystem.

## Contents

Currently, the repository contains simple foundational exercises:

*   **`HelloWorld.cs`**: The classic first program in any language.
*   **`variables.cs`**: Exploring data types and variable declarations in C#.
*   **`ForLoop.cs`**: Understanding basic control flow and iteration.

## Goal

The main objective here is to build a strong foundational understanding of C# before moving on to more complex projects and frameworks. This repo will evolve as I learn more advanced topics!
